# Conexión Java y MySQL

Proyecto desarrollado en Java que permite conectar una aplicación con una base de datos MySQL utilizando JDBC.

## Tecnologías
- Java
- MySQL
- JDBC
- NetBeans

## Funcionalidades
- Conexión a base de datos
- Inserción de datos
- Consultas SQL
- Actualización y eliminación

## Cómo ejecutar
1. Clonar repositorio
2. Importar en NetBeans
3. Configurar MySQL
4. Ejecutar Main.java
